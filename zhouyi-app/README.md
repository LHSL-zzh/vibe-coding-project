# 周易起卦（zhouyi-app）

三枚硬币法六爻占筮的纯前端网页应用。无构建、零依赖，部署于 GitHub Pages。

- 在线使用：https://LHSL-zzh.github.io/vibe-coding-project/zhouyi-app/

## 功能

- **两种起卦方式**
  - 自动模拟：电脑随机三枚硬币，逐爻 3D 翻转揭晓
  - 手动掷币：自备三枚真硬币，逐爻点选每枚「字(正)/背(反)」
- **排盘**：自下而上六爻 → 本卦（卦画、卦名、上下卦）→ 动爻翻转 → 变卦
- **文本**：卦辞 + 大象辞 + 六爻爻辞（动爻高亮 ● ○），《周易》通行本公版原文
- **历史记录**：localStorage 保存最近 12 次，可回看

## 起卦规则（三枚硬币法）

每枚硬币 字(正) 计 3、背(反) 计 2，三枚合计：

| 合计 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|
| 名称 | 老阴 ● | 少阳 | 少阴 | 老阳 ○ |
| 阴阳 | 阴 | 阳 | 阴 | 阳 |
| 动爻 | 动 | — | — | 动 |

掷六次自下而上成卦（初爻 → 上爻）；6、9 为动爻，阴阳互变即得变卦。

## 本地运行

浏览器禁止 `file://` 页面 fetch 本地 JSON，请用静态服务器：

```bash
python3 -m http.server 8000      # 在 zhouyi-app/ 目录下
# 访问 http://localhost:8000/
```

## 测试

```bash
node tests/run-tests.cjs         # 核心逻辑自测（数据/概率/变卦闭包等）
```

## 数据说明

卦辞爻辞为《周易》通行本古籍原文（公版），由 `tools/build_guaci.py`
从公开参考数据整理并做脚本级校验（卦名集合=通行本、爻名阴阳与卦画对应、
变卦闭包全遍历）；建议仍对照通行本做一次人工终审。
