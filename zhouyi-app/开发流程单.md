# 周易算卦 (zhouyi-app) — 开发流程单

> 构思：用抛硬币的方式起卦，共抛六次、每次得出一爻（自下而上），
> 六爻成卦后显示卦象（卦画、卦名、上下卦）与卦辞、爻辞，有动爻时显示变卦。

## 1. 项目目标

点击起卦 → 依次抛出 6 次硬币（每次动画+正反结果）→ 自下而上排出六爻
→ 由下三爻（内卦）+ 上三爻（外卦）查 64 卦表 → 显示：

- 卦象（阴阳爻组成的卦画）
- 卦名与上下卦名（如「乾为天」「水雷屯」）
- 卦辞 + 六爻爻辞（动爻高亮并给出变卦）

形态：**纯前端网页应用**（无后端），可部署 GitHub Pages，手机/电脑浏览器直接打开。

**结论**：
- **六爻硬币起卦的算法已有成熟先例**：三枚硬币掷六次，每爻得 6/7/8/9（老阴/少阳/少阴/老阳），6、9 为动爻；动爻变后得变卦。规则明确、无需训练任何模型
- **没有高 star 的「纯前端硬币起卦小应用」**：现有多为 Python 库 / AI 技能 / 重型算命平台，轻量、可直接打开的网页版反而是空白，适合 vibe coding 快速完成
- 64 卦卦辞爻辞为古籍公版文本，可从上述项目数据中提取整理（组织方式参考，文本以《周易》通行本为准）
- 技术栈选择：**原生 HTML/CSS/JS（零依赖，单页即可）**，比 Python+Streamlit 更适合「打开即用」的网页应用

## 3. 技术选型

| 模块 | 方案 | 备注 |
|---|---|---|
| 应用形态 | 纯静态网页（原生 HTML/CSS/JS，无构建工具） | 打开即用，GitHub Pages 直接部署；不引入框架保持简单 |
| 起卦算法 | 三枚硬币法：每枚正=3/反=2，三枚和 6/7/8/9 → 老阴/少阳/少阴/老阳；6、9 为动爻 | 正统六爻法；另提供「单枚硬币」简化模式（正=阳、反=阴，无动爻） |
| 随机数 | Math.random 模拟硬币（避免真随机偏差，分布满足 6:1/8、7:3/8、8:3/8、9:1/8） | 支持「手动模式」：用户自己抛真硬币后点选正反 |
| 卦象计算 | 六爻自下而上编号 1~6；下三爻=内卦、上三爻=外卦；先天八卦序号组合查 64 卦表 | 卦表用二进制映射（0=阴 1=阳），可靠且不易错 |
| 数据 | `guaci.json`：64 卦 ×（卦序号、卦名、上下卦名、卦辞、6 条爻辞、动爻提示可选） | 共 64 卦辞 + 384 爻辞；来源《周易》通行本，整理时对照 kentang2017/ichingshifa 与 chengjun/iching 数据 |
| 交互/动画 | 抛硬币 3D 翻转动画（CSS transform + JS 定时翻转），六爻自下而上逐爻生成 | 手机端适配（响应式布局） |
| 历史记录 | localStorage 保存最近 N 次起卦记录 | 可选增强 |

## 4. 系统架构

```
用户点击「起卦」
    │
    ▼
抛币引擎（6 次循环，每次模拟 3 枚硬币 → 6/7/8/9）
    │  动画显示每爻结果，自下而上排列
    ▼
六爻排盘（初爻→上爻，记录动爻位置）
    │
    ▼
卦象计算（内卦=下三爻，外卦=上三爻 → 先天序 → 64 卦表查卦名）
    │
    ├── 有动爻? ──是──▶ 动爻阴阳互变 → 变卦
    │                       │
    ▼                       ▼
本卦展示                    变卦展示
（卦画 + 卦名 + 卦辞 + 爻辞）  （卦画 + 卦名 + 变卦卦辞）
    │
    ▼
结果页：卦象图 + 卦辞 + 爻辞（动爻高亮）+ 重新起卦
```

## 9. 二期规划（暂缓，一期完成后再做）：卦辞古籍线条画

> 目标：展示卦辞/爻辞时，根据卦辞内容配一幅古籍风格线条画，
> 让"卦辞 → 画面"立起来。流程：
> 六爻结果 → 检索对应卦辞 → 文言文译成现代文（**此步不展示**）
> → 依据描述生成古籍线条画 → 与卦辞一同展示。

### 9.1 调研结论（2026-08）

- **无现成成品开源项目**（"卦辞→古籍线画"是细分空白），需自研管线
- **关键洞察：有限集合问题**——64 卦卦辞为固定文本，意象有限。
  每卦配一张固定线画（有动爻时再多一张变卦图，≤128 张封顶），
  **离线批量生成一次 → 打包成静态资源 → 网页按卦索引**，
  零运行时成本、风格统一、契合纯前端定位
- 翻译层：开源专用模型偏弱（Scagin/Classical2Modern ★36、
  Bureaux-Tao/unilm-translate-ancient_chinese ★9、语料 C2MChn ★7），
  现代大模型（Qwen/GLM/GPT）文言翻译质量碾压，宜**离线批量翻译**
- 线画层候选路线：
  - A. 扩散模型 + ControlNet lineart（白描/木刻/绣像风格），
    先例 JunQHuang/Shan-Hai-Jing-Style-Transfer（SD+LoRA 古籍风格）
  - B. LLM 直接写 SVG 线画（矢量无损、可做逐笔描画动画，需逐卦调优）
  - C. 学术草图生成 DiffSketcher ★310（研究性质，仅参考）
  - D. 真实古籍插图做风格地基：zhuth/AncientIllus（首图古籍插图库爬虫）
